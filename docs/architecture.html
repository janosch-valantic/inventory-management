Key Design Decisions

No Database

All data lives in JSON files loaded into Python lists at startup. No persistence between restarts — intentional for a demo environment with no infrastructure dependencies.

Filter Persistence

useFilters() is a singleton composable. Filter selections persist across navigation — switching from Orders to Dashboard keeps the same warehouse/period selected without URL-based state.

Quarter-Aware Filtering

filter_by_month() in the backend understands "Q1-2025" and expands it to months 01–03. Supports both individual months (2025-01) and quarters (Q1–Q4) in the same param.
